# Electron 本地便签

必须运行实际 Electron 桌面应用。项目 README 给出构建和启动方式，接受独立用户数据目录。不依赖公网或真实用户数据。

- NOTE-01：可以新建、选择、编辑、删除便签。每个便签有不变的独立 ID；两个同标题便签独立编辑、删除。
- NOTE-02：标题去除首尾空白后必须为 1 至 80 个 Unicode 码点，正文为 0 至 10000 个 Unicode 码点。非法保存显示可见错误且不覆盖最近一次成功保存；错误文案不作要求。
- NOTE-03：成功保存后完全退出应用再启动，标题与正文一致；删除结果也保留。不同用户数据目录互不影响。
- NOTE-04：正文与标题作为普通文本展示，不解释 HTML 或脚本。渲染界面不能直接访问 Node 的 require、process 或文件系统。
- NOTE-05：渲染端只能通过明确的便签 IPC 接口访问数据。向存储/删除接口提交 `../outside` 等越界 ID，应拒绝且不能在用户数据目录外产生或修改文件；具体报错形式不作要求。
- NOTE-06：未选择便签时，保存/删除不得损坏现有数据；关闭后没有残留的本应用 Electron 进程。其他同时运行的 Electron 应用不在本需求范围内。
