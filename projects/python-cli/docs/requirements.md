# CSV 金额汇总 CLI

运行入口由项目 README 给出，接受 `--input <UTF-8 CSV 文件>`。不依赖网络。

- INV-01：CSV 必须且仅有 `account,amount_cents` 两列表头，顺序如此。account 是非空 ASCII 字母数字串；amount_cents 是 0 至 1000000000 的十进制整数。空文件、无数据行、坏表头、坏记录应失败。
- INV-02：按 account 汇总所有记录的 amount_cents，使用精确整数计算。一个 account 的结果可以超过 32 位有符号整数最大值。
- INV-03：成功时标准输出为一个 JSON 对象，字段为 `totals`（account 到整数总额的对象）与 `row_count`（数据行数），退出码为 0。JSON 键顺序及空白不作要求，标准错误为空。
- INV-04：缺少参数、未知参数、输入文件不存在或输入不合法时，退出码为 2；标准错误包含非空诊断；标准输出为空，不输出部分汇总。具体诊断措辞不作要求。
- INV-05：不能修改输入文件，也不能在输入目录写入其他文件。使用者可从任意工作目录以绝对输入路径执行。
- INV-06：同一输入重复执行得到相同汇总。账号大小写敏感，`A` 与 `a` 分开统计；不对 account 做大小写转换。
