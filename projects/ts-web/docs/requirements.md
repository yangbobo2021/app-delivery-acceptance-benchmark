# 浏览器待办管理

项目 README 给出构建和 localhost 启动方式。通过真实浏览器操作界面；无后端服务或账户系统。

- TODO-01：输入非空标题并添加后，列表出现该待办。标题首尾空白会去除；全空白或去除后超过 80 个 Unicode 码点的标题不能添加，并显示可见错误。错误文案不作要求。
- TODO-02：可以切换待办完成状态，再次切换可恢复未完成。两个标题相同的待办是不同条目，切换一个不影响另一个。
- TODO-03：提供全部、未完成、已完成三个过滤选项。可见列表与所选过滤一致；切换过滤不修改待办状态。
- TODO-04：显示所有待办中的未完成总数，不能只统计当前过滤结果。空列表时为 0。
- TODO-05：可以删除指定待办，删除其他同名待办不受影响。刷新页面后，条目、完成状态与删除结果保留；不同浏览器存储上下文互不影响。
- TODO-06：标题作为普通文本展示。`<img src=x onerror=alert(1)>` 是合法短标题，不得创建对应图片元素或执行其中代码。列表排序、视觉设计、刷新后默认过滤均不作要求。
